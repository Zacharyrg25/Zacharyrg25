## 🚀 Projects

### 🎮 [Wordle 98](https://github.com/zacharyrg25/wordle98)
A remake of the NYT Wordle game with a Windows 98 aesthetic. Features dynamic word length (4–8 letters), live dictionary validation, a two-pass duplicate-letter scoring algorithm, draggable Win98-style modals, and post-game word definitions.

> `HTML` `CSS` `JavaScript` `Dictionary API` `Random Word API`

---

### 🔍 [Face Detection Web App](https://github.com/zacharyrg25/face-detection)
A Flask web app that detects faces in uploaded images using two methods side-by-side: classic Haar Cascades and the deep learning-based MTCNN model. Results are drawn directly onto a canvas in the browser.

> `Python` `Flask` `OpenCV` `MTCNN` `TensorFlow` `NumPy` `JavaScript`
